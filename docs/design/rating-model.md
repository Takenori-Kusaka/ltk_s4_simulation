# 評価モデルの設計(F-009 / ADR-0004)

F-009 の受入基準を満たすための具体的な式と、初期値の起案。**この文書の数値と常識の一覧は AI の起案であり、価値責任者の確定を要する**(F-009 未確定事項)。根拠は `docs/research/rating-methods.md`(既存の評価システムと学術モデルの調査)と、2026-10-08 の実データの分析(60 選手、参加者のべ 16,490 人分)。

## 1. 全体の式

```
データの軸の点数 = clamp( A × r + 5.0 × (1 − r) + 1.5 × P × n / (n + k), 0, 10 )
  A : ランクの基準(0〜10。Iron IV 0LP=0.0 / Gold IV=3.4 / Diamond IV=6.9 / Master 0LP=8.0 / Master 1500LP 以上=10.0)
  r : 軸のランクの重み(その軸がどれだけランクで決まるか)
  P : 補正 = 指標ごとの「対面との差」を母集団の同じロールの分布で標準化した値(z)の、指標の重みと新しさの重みによる平均
  n : 有効な試合数(新しさの重み 0.5^(日数/45) の和)
  k : 縮小の強さ(初期値 8。n = 8 のとき補正は半分に縮む)
```

- 補正 P は「同じ MMR 帯の相手より上か下か」を表す(ソロキューは同じ MMR 帯で組まれる)。実データでも対面との差の指標はランクとほぼ無相関だった(最大 CS 差 0.10、視界の差 −0.02、対面比ダメージ 0.24)。だからランクの基準 A に足しても二重に数えない
- 1.5 は「対面より 1 標準偏差上なら 1.5 点上」を意味する。ランクの基準から外れられる幅を ±3 点程度に抑える(Gold の選手が Master の選手を上回るには、対面を 2 標準偏差以上上回り続ける必要がある)
- z は ±3 で切る(外れ値の抑え込み)

## 2. 軸の定義(起案)

| 軸 | r | 使う試合 | 指標(対面との差を標準化) と重み | 上限・注意 |
| --- | --- | --- | --- | --- |
| メカニクス | 0.8 | 評価の試合(ロールを問わない) | 対面比ダメージの対数 0.5 / ソロキルの差 0.3 / 最初の数分の関与(takedownsFirstXMinutes)の差 0.2 | ランクの効きが最も強い |
| レーン戦 | 0.5 | 大会のロールの試合 | TOP・MID・ADC: 最大 CS 差 0.4 / レーン戦の優位の割合(laningPhaseGoldExpAdvantage)0.3 / 最大レベル差 0.3。JG: 敵のジャングルのモンスター 0.3 / スカトル 0.2 / 序盤の関与 0.5。SUP: 視界の差 0.5 / 序盤の関与 0.5 | ロールごとに指標を変える |
| 集団戦 | 0.5 | 大会のロールの試合 | キル関与率の差 0.4 / ダメージ割合の差 0.3(TOP・JG・SUP はダメージを受けた割合の差に置き換え)/ 行動妨害の回数の差 0.2 / 味方を救った回数 0.1 | — |
| 視界 | 0.3 | 大会のロールの試合 | 分あたり視界スコアの差 0.5 / コントロールワードの差 0.3 / ワードの破壊の差 0.2 | ロールの違いは対面との差で吸収する |
| オブジェクト | 0.4 | 評価の試合 | ドラゴン・バロン・ヘラルドの関与の差 0.5 / タワーの関与の差 0.3 / タワーのプレートの差 0.2 | **7.0 以下**(マクロの定性の根拠があるときだけ外す) |
| チャンピオンプール | 0.3 | 大会のロールの試合 | 3 試合以上遊んだチャンピオンの数(母集団ではなく 60 選手のロール内の分布で標準化)0.5 / それらの勝率(試合数で縮小)0.5 | 事前値にサモナーレベル・熟練度の合計を使う |
| 大会経験 | — | 調査の出典つきの記録 | LTK の出場試合数(0→2.0、40 以上→8.0、対数)/ LTK の勝率(試合数で縮小、±1.0)/ プロの経歴(LJL 等の出場年数、最大 +2.0) | 出典の無い経歴は数えない |
| コール | — | 出典つきの定性の根拠 | 根拠ごとの 0〜10 の評価の平均。AI の下書きだけなら「AI 推定(未確認)」 | **根拠が無ければデータなし** |

## 3. 確度

| 確度 | データの軸 | 根拠の軸 |
| --- | --- | --- |
| 高 | 有効な試合数 15 以上(ロール依存の軸は大会のロールの試合) | 人が確認した出典 2 件以上 |
| 中 | 6 以上 15 未満 | 人が確認した出典 1 件、または AI の下書き |
| 低 | 6 未満、または事前値だけ | — |

ソロランクが無い選手は全データの軸の確度を 1 段下げる(F-009 基準9)。

## 4. 事前値(データの無い軸の出発点)

- メカニクス・レーン戦・集団戦・視界・オブジェクト: ランクの基準 A(ソロランク → 調査の最高ランク → 母集団の中央値の順)
- チャンピオンプール: サモナーレベルと熟練度の合計の、60 選手の中での位置(遊んだ量。技量には使わない)
- 大会経験: 調査の LTK 戦績とプロ経歴(無ければ 2.0 = 初出場)
- コール: 事前値を作らない(データなし)

## 5. 2026-10-08 の実データで分かった、確度を下げるべき選手(常識の一覧の候補)

| 選手 | 事象 | 期待する扱い |
| --- | --- | --- |
| SHAKA(DD NEXT TOP) | 大会のロール(TOP)の試合が 29 試合中 2 | レーン戦・視界・集団戦の確度「低」 |
| Rainbrain(CC MASTERS JG) | JG の試合が 2、直近 60 日の試合 0 | 同上、全体の確度を下げる |
| アステル・レダ(LR NEXT JG) | JG の試合が 3 | 同上 |
| 鷹宮リオン(CC NEXT SUP) | SUP の試合 6、今季ソロ未ランク、最後の試合が約 440 日前 | 全データの軸が「推定」 |
| じゃすぱー(DD CORE ADC)・ハレっち(LR MASTERS ADC) | 直近 60 日の試合が 0 | 120 日の期間の外の試合は除く → 確度を下げる |

## 6. 常識の一覧の候補(価値責任者が確定する)

| # | 条件(機械で検査する形) | 意図 |
| --- | --- | --- |
| K-01 | ランクの基準の差が 3.0 以上ある同じロールの2選手で、メカニクスの点数が逆転しない | Challenger が Gold に負けない |
| K-02 | 大会のロールの試合が 5 未満の選手は、レーン戦の確度が「低」 | ロール外の試合で語らない |
| K-03 | 出典つきのコールの根拠が無い選手は、コールが「データなし」 | 「コールできないのに高い」を防ぐ |
| K-04 | マクロの定性の根拠が無い選手は、オブジェクトが 7.0 以下 | 「マクロを分かっていないのに高い」を防ぐ |
| K-05 | MASTERS の元プロ(LJL 出場経歴あり)は、LTK 初出場の NEXT の選手より大会経験が高い | 経歴の常識 |
| K-06 | 全選手の全軸の点数が 0.0〜10.0 で、確度が付いている | 形式 |
| K-07 | 同じ選手の点数が、同じ入力・同じ基準日で毎回一致する | 再現性 |

## 7. 根拠の軸の材料(作業)

- 大会経験: `docs/research/format-history.md` 節6(Finale 出場者の過去の LTK 戦績)と、選手の調査のプロ経歴を、出典つきのスナップショット(F-003 Task-3 の形)にする
- コール: 選手の調査の「コール・IGL」の記述(例: 乾伸一郎の S1 での評価、ゆふなの前季優勝リーダー)を出典つきで拾い、無い選手は空のままにする。Gemini の下書き(F-003 Task-4)は「AI 推定(未確認)」として入れ、価値責任者が確認する
