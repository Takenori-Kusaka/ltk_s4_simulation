# 評価モデルの設計(F-009 / ADR-0004)

F-009 の受入基準を満たすための具体的な式と、初期値の起案。**この文書の数値と常識の一覧は AI の起案であり、価値責任者の確定を要する**(F-009 未確定事項)。根拠は `docs/research/rating-methods.md`(既存の評価システムと学術モデルの調査)と、2026-10-08 の実データの分析(60 選手、参加者のべ 16,490 人分)。

## 1. 全体の式

```
データの軸の基礎の点数 = clamp( A × r + 5.0 × (1 − r) + 1.5 × P × n / (n + k) + L, 0, 10 )
  L : LTK の経験の項(集団戦・連携・安定感だけ。参加シーズン数 × 0.4、上限 1.2)
表示の点数 = clamp( 基礎の点数 + (調子の係数 − 1) × 5, 0, 10 )  … 加算で ±0.5 点まで。好調なら実力帯に依らず上がる(2026-10-09 価値責任者が確定)
  A : ランクの基準(0〜10。Iron IV 0LP=0.0 / Gold IV=3.4 / Diamond IV=6.9 / Master 0LP=8.0 / Master 1500LP 以上=10.0)
  r : 軸のランクの重み(その軸がどれだけランクで決まるか)
  P : 補正 = 指標ごとの「対面との差」を母集団の同じロールの分布で標準化した値(z)の、指標の重みと新しさの重みによる平均
  n : 有効な試合数(新しさの重み 0.5^(日数/45) の和)
  k : 縮小の強さ(初期値 8。n = 8 のとき補正は半分に縮む)
```

- 補正 P は「同じ MMR 帯の相手より上か下か」を表す(ソロキューは同じ MMR 帯で組まれる)。実データでも対面との差の指標はランクとほぼ無相関だった(最大 CS 差 0.10、視界の差 −0.02、対面比ダメージ 0.24)。だからランクの基準 A に足しても二重に数えない
- 1.5 は「対面より 1 標準偏差上なら 1.5 点上」を意味する。ランクの基準から外れられる幅を ±3 点程度に抑える(Gold の選手が Master の選手を上回るには、対面を 2 標準偏差以上上回り続ける必要がある)
- z は ±3 で切る(外れ値の抑え込み)

## 2. 個人の軸の定義(起案)

価値責任者の指示(2026-10-08)で、チームゲームとしての LoL での個人の働きを測る軸にした。

| 軸 | ランクの重み r | 使う試合 | 指標(対面との差を標準化)と重み | LTK の経験の項 |
| --- | --- | --- | --- | --- |
| 地力 | 0.8 | 評価の試合(ロールを問わない) | 対面比ダメージの対数 0.4 / 対面との分あたりゴールドの差 0.4 / ソロキルの差 0.2 | なし |
| レーン戦 | 0.5 | 大会のロールの試合 | TOP・MID・ADC: 最大 CS 差 0.4 / レーン戦の優位の割合(laningPhaseGoldExpAdvantage)0.3 / 最大レベル差 0.3。JG: 敵のジャングルのモンスター 0.3 / スカトル 0.2 / 序盤の関与(takedownsFirstXMinutes)0.5。SUP: 視界の差 0.5 / 序盤の関与 0.5 | なし |
| 集団戦 | 0.5 | 大会のロールの試合 | ダメージ割合の差 0.5(TOP・JG・SUP はダメージを受けた割合の差に置き換え)/ 行動妨害の回数の差 0.3 / 数的不利でのキル(outnumberedKills)の差 0.2 | あり |
| 連携 | 0.3 | 大会のロールの試合 | キル関与率の差 0.4 / 味方と取ったキル(pickKillWithAlly・knockEnemyIntoTeamAndKill)の差 0.3 / 味方を救った回数・回復とシールドの差 0.3 | あり |
| 安定感 | 0.4 | 評価の試合 | 対面より少ないデス(分あたり、符号を反転)0.6 / 試合ごとの出来(地力の補正)のばらつきの小ささ 0.4 | あり |
| ピックプール | 0.3 | 大会のロールの試合 | 3 試合以上遊んだチャンピオンの数(60 選手のロール内の分布で標準化)0.5 / それらの勝率(試合数で縮小)0.5 | なし(事前値にサモナーレベル・熟練度・LoL 歴) |
| コール力 | — | 出典つきの根拠 | 肯定の根拠(選手としてのコール・コーチとしての指示・他ゲームの IGL を同等に数える)の強さで 5.0〜9.5(強 +1.5、中 +1.0、弱 +0.5 を 5.0 に積む、上限 9.5)。否定の根拠があれば上限 4.0。肯定の根拠が無ければ 2.5(実績なし) | — |
| 大会経験 | — | 出典つきの記録 | LTK の参加シーズン数(1 で 4.0、2 で 5.5、3 で 6.5)/ LTK の出場試合数と勝率(試合数で縮小、±1.0)/ 他の大会とプロの経歴(LJL の出場年数で最大 +2.0、他の大会で最大 +1.0) | — |

LTK の経験の項(集団戦・連携・安定感): 参加シーズン数 × 0.4、上限 1.2。価値責任者「LTK の1シーズンの学びはソロキュー1年より圧倒的に上」による。

## 2b. チームの指標(チームのページだけ)

| 指標 | 材料 |
| --- | --- |
| 視界 | 所属選手の分あたり視界スコアの対面との差、コントロールワード、ワードの破壊(ロール別に標準化し、階級ごとに平均) |
| オブジェクト | 所属選手のドラゴン・バロン・ヘラルド・タワーへの関与の対面との差 |
| マクロ | 出典つきの定性の根拠(チームとしての運営の評価、過去の LTK での運営の記述)。根拠が無ければデータなし |

## 2c. 調子の係数

```
調子の係数 = clamp( 1.00 + 0.10 × S, 0.90, 1.10 )
  S = 0.5 × (直近14日の勝率 − 0.5) / 0.15 × m/(m+5)  … 勝率(試合数 m で縮小)
    + 0.3 × LP の増減 / 150                        … ソロランクの LP の増減(Master 以上は LP、未満はディビジョンを 100LP に換算)
    + 0.2 × min(m, 30) / 30 × 符号なし              … 練習量(試合数。多いほどわずかに上げる)
  S は −1〜+1 に切り詰める。直近14日の評価の試合が 3 件未満なら係数 1.00「判断材料なし」
```

## 3. 確度

| 確度 | データの軸 | 根拠の軸 |
| --- | --- | --- |
| 高 | 有効な試合数 15 以上(ロール依存の軸は大会のロールの試合) | 人が確認した出典 2 件以上 |
| 中 | 6 以上 15 未満 | 人が確認した出典 1 件、または AI が集めた出典(未確認) |
| 低 | 6 未満、または事前値だけ | — |

ソロランクが無い選手は全データの軸の確度を 1 段下げる(F-009 基準9)。

## 4. 事前値(データの無い軸の出発点)

- 地力・レーン戦・集団戦・連携・安定感: ランクの基準 A(ソロランク → 調査の最高ランク → 母集団の中央値の順)。集団戦・連携・安定感には LTK の経験の項も加える
- ピックプール: サモナーレベル・熟練度の合計・LoL 歴(出典のある選手だけ)の、60 選手の中での位置(遊んだ量。技量には使わない)
- 大会経験: 調査の LTK 戦績とプロ経歴・他の大会(LTK も他の大会も無ければ 2.0)
- コール力: 肯定の根拠が無ければ 2.5(実績なし。価値責任者の指示)。ランクや地力からは推定しない

## 5. 2026-10-08 の実データで分かった、確度を下げるべき選手(常識の一覧の候補)

| 選手 | 事象 | 期待する扱い |
| --- | --- | --- |
| SHAKA(DD NEXT TOP) | 大会のロール(TOP)の試合が 29 試合中 2 | レーン戦・視界・集団戦の確度「低」 |
| Rainbrain(CC MASTERS JG) | JG の試合が 2、直近 60 日の試合 0 | 同上、全体の確度を下げる |
| アステル・レダ(LR NEXT JG) | JG の試合が 3 | 同上 |
| 鷹宮リオン(CC NEXT SUP) | SUP の試合 6、今季ソロ未ランク、最後の試合が約 440 日前 | 全データの軸が「推定」 |
| じゃすぱー(DD CORE ADC)・ハレっち(LR MASTERS ADC) | 直近 60 日の試合が 0 | 120 日の期間の外の試合は除く → 確度を下げる |

## 6. 常識の一覧(初版。K-01〜K-07 は 2026-10-08、K-08・K-09 は 2026-10-09 に価値責任者が確定)

| # | 条件(機械で検査する形) | 意図 |
| --- | --- | --- |
| K-01 | ランクの基準の差が 3.0 以上ある同じロールの2選手で、地力の基礎の点数が逆転しない | Challenger が Gold に地力で負けない |
| K-02 | 大会のロールの試合が 5 未満の選手は、レーン戦の確度が「低」 | ロール外の試合で語らない |
| K-03 | 肯定の根拠が無い選手のコール力は 2.5 以下、否定の根拠がある選手は 4.0 以下 | 「コールできないのに高い」を防ぐ |
| K-04 | 価値責任者が「コールしない側」と確認した選手(龍巻ちせ・叶・空澄セナ・獅子堂あかり)のコール力は 4.0 以下。マクロの根拠が無いチームはマクロが「データなし」 | 根拠と点数の向きの矛盾を防ぐ |
| K-05 | MASTERS の元プロ(LJL 出場経歴あり)は、LTK 初出場の NEXT の選手より大会経験が高い | 経歴の常識 |
| K-06 | 全選手の全軸の点数が 0.0〜10.0 で、確度が付いている | 形式 |
| K-07 | 同じ選手の点数が、同じ入力・同じ基準日で毎回一致する | 再現性 |
| K-08 | 結果が入る前、NEXT と CORE の階級チーム同士で勝率が 0.80 を超える組が無い | 過信を防ぐ(実力差の上限からの見込みは典型 69%) |
| K-09 | 勝率が全組 0.45〜0.55 に収まっていない | 平らすぎる予測を防ぐ |

## 7. 根拠の軸の材料(作業)

- 大会経験: `docs/research/format-history.md` 節6(Finale 出場者の過去の LTK 戦績)と、選手の調査のプロ経歴を、出典つきのスナップショット(F-003 Task-3 の形)にする
- コール力: 2026-10-08 に調査エージェント2名で全 60 名の根拠(LTK と他の大会での役割、本人・チームメイトの発言、記事、X・ブログ・YouTube を含む視聴者の声)を収集中。肯定と否定の両方を出典つきで入れ、「AI 収集(未確認)」として表示し、価値責任者が確認して外す。LTK 出場者 58 名で根拠が見つからない場合は収集の不足として追加で探す
