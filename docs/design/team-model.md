# 階級チームと全階級チームの評価の設計(F-010 / ADR-0005)

> **2026-10-09 確定(価値責任者)**: docs/design/team-model-algorithm.md の推奨を採る。選手の総合は個人の8軸の等しい重み(各 1/8。ランクの実効の寄与を画面に示す)、ロールの重みは価値責任者の値、勝率の尺度は戦力の差1点あたり対数オッズ 2.0(S2 で当てはめ)、本番の結果(重み 1)とスクリム(重み 0.25)による日次の補正、勝率と優勝確率に 80% の区間。下の表の暫定の式(差 4 点で 91%)はこれで置き換わる。

F-010 の受入基準を満たす式と初期値の起案。**数値は AI の起案であり、価値責任者の確定を要する**(F-010 未確定事項)。確定済みの方針(2026-10-08、価値責任者): ロールの重みの順序、コーチとしての指示をコール力の根拠に数える、フィアレスへの強さとウィークサイドの設計を総合力に含める。

記号: 個人の軸の表示の点数(F-009、調子の係数を掛けた後)を `x[選手][軸]`、相対評価の換算(F-002 基準6)を `rel(·)`(同じ階級の4チームで 5.0 + 2.0 × z、0〜10)とする。

## 1. 階級チームの強さの軸(4チームの相対評価)

| 軸 | 素点の式(相対評価の前) | 確度 |
| --- | --- | --- |
| 戦力 | Σ ロールの重み × 選手の総合。選手の総合 = 個人の8軸すべて(地力・レーン戦・集団戦・連携・安定感・ピックプール・コール力・大会経験)の加重(価値責任者の指示「選手の評価軸すべてを使って総合力が決まるべき」。重みの決め方は別途の検討 §5)。ロールの重み MID 0.24 / JG 0.21 / SUP 0.21 / TOP 0.17 / ADC 0.17 | 5人の確度の最小 |
| 連携の厚み | 5人の (連携 + 集団戦) / 2 の平均 + LTK で同じ階級チームの組 × 0.1 | 同上 |
| 司令塔 | コール力の最大値 × 0.7 + (コール力 6.0 以上の選手がちょうど1人なら 3.0、2人なら 2.0、0人なら 0) × 0.3。全員データなしなら データなし | 最大の選手の確度 |
| 継続性 | 過去の LTK で同じチーム・同じ階級で出場した選手の組の数(5人で最大 10 組)÷ 10 × 10 | 高(公式の記録) |
| 指導 | 担当コーチの経歴(プロ経歴 +3、LTK のコーチ経験1シーズンごと +1、上限 +5)+ 階級チームの最も弱い軸を補う知見の根拠(1件 +1、上限 +3)+ 2.0 | 根拠の数 |
| ピックの幅 | 5人のピックプールの平均 − NEXT と CORE の得意チャンピオン(各選手の上位5体)の重なりの数 × 0.3 | 5人の確度の最小 |
| フィアレス耐性 | 各ロールで「勝率 50% 以上かつ 3 試合以上」のチャンピオンの数のうち小さい方から3ロールの平均(シリーズで3試合戦えるか)。MASTERS では重みを 1.5 倍で総合の MASTERS CUP の力に効かせる | 同上 |

## 2. 戦い方の特性(両極の目盛り。−1.0〜+1.0)

| 特性 | 式 | 材料が無いとき |
| --- | --- | --- |
| 序盤型 ⇄ 終盤型 | (14 分までの K+A/分 ÷ 14 分以降の K+A/分 − 母集団の中央値) を標準化。+ が序盤型 | データなし |
| レーン戦重視 ⇄ 集合重視 | 14 分時点のレーンのゴールド差の絶対値の平均(大きいほどレーン戦重視)と、14 分までの KP(高いほど集合重視)の差 | データなし |
| 重心 | ロールごとのゴールド割合 0.5 + ダメージ割合 0.3 + 個人の(地力 + レーン戦)の偏り 0.2 を TOP・JG・MID・BOT(ADC+SUP)の割合として示す | 個人の偏りだけ(確度 低) |
| オブジェクトの優先度 | 5人のソロキューのドラゴン・バロン・ヘラルド・タワーの関与の対面との差の平均 + 過去の LTK の記録 + 出典つきの記述 | 個人のデータだけ(確度 低) |
| 視界の管理 | 5人の分あたり視界スコア・コントロールワード・ワードの破壊の対面との差の平均 | 同上 |
| ウィークサイドの候補 | TOP・ADC・MID のうち 安定感 × 0.6 + レーン戦の補正の崩れにくさ(資源の少ない試合での対面との差の分散の小ささ)× 0.4 が最も高い選手のレーン | 安定感だけ(確度 低) |

過去の LTK の記録(LTK3 の公開スプレッドシート)は、継続した選手が2人以上の階級チームだけに使い、継続の割合を確度にする。Finale のスクリム・本番の記録が入ったら優先する。

## 3. 全階級チームの総合の軸(0〜10)

前提: 階級チーム同士の1試合の勝率を `p(階級, 自, 相手) = 1 / (1 + 10^(−(強さ_自 − 強さ_相手) / 4))` で見込む(強さは階級チームの戦力と連携の厚み・司令塔の加重。差が 4 点で約 91%)。この式は F-005 が確定させるまでの仮のもの。

| 軸 | 式(起案) |
| --- | --- |
| Regular Stage の得点力 | 相手3チームとの平均の期待得点 = p_NEXT + p_CORE + p_NEXT × p_CORE(同日の両勝ちの +1pt)。最大 3.0 を 10 点に写す |
| MASTERS CUP の力 | MASTERS の強さの相対評価 × 0.7 + フィアレス耐性の相対評価 × 0.3 |
| エースの階級 | 3階級の階級チームの強さの相対評価の最大値(階級名も示す) |
| 階級の均衡 | 10 − 3階級の相対評価の標準偏差 × 2(0〜10) |
| コーチングの活用 | CORE と NEXT のそれぞれで、(担当コーチの指導の素点 ÷ 10)×(10 − その階級チームの最も弱い軸)を平均し、0〜10 に写す。弱点が大きく、それを補えるコーチほど高い |
| 一体感 | 階級をまたいだ過去の共闘の組の数 × 0.5(上限 4)+ チーム全体のリーダーの根拠(1件 +1、上限 3)+ (3 − NEXT と CORE の得意チャンピオンの重なり ÷ 5)(0〜3) |
| チーム設計 | 3階級のウィークサイドの候補の確かさ(候補と二番目の差、0〜1)の平均 × 6 + 担当コーチがウィークサイドの作り方に通じている根拠(1件 +1、上限 4) |

優勝確率(F-001)は総合の軸とは別に、結論として並べて示す。総合の軸は「なぜその確率か」の説明に使う。

## 5. より信頼できる算出方法の検討(2026-10-08 に依頼)

価値責任者の指示「ここのアルゴリズムは信頼性を必要とするもので、適当に 100% を配分すればいい話ではない」により、重みと勝率の見込みの式を、過去の LTK の結果での検証を含めて別途検討する(調査エージェント)。結果は docs/design/team-model-algorithm.md に置き、この表の暫定値を置き換える。
