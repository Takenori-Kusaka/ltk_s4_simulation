## 1. エグゼクティブサマリー

2026年10月15日から11月22日にかけて開催された『League of Legends』の大型ストリーマー大会「League The k4sen Season: Finale (LTK Season 4)」は、オフライン決勝（千葉JPFドーム）をもって全日程を終了しました。

本シミュレーター（crinoid）は、ソロランク指標、過去のLTK実績、有識者の外部見立て、スクリム結果などを組み合わせた3層評価モデル（個人8軸レーダー・チーム戦力S・マクロM・仕上がり・連敗補正・ベイズ更新）により、全試合の勝率および優勝確率を予測・シミュレーションしてきました。

### 大会最終結果
* 🏆 **優勝**: **Camellia Crown (CC / カメリア・クラウン)**
* 🥈 **準優勝**: **Iris Tiara (IT / アイリス・ティアラ)**
* 🥉 **3位**: **Laurel Regalia (LR / ローレル・レガリア)**
* 4位: **Dahlia Diadem (DD / ダリア・ディアデム)**

### シミュレーター予測の総括
* **総合的中率**: レギュラーステージ前半および高確信度カードにおいて **70%超** の高い的中精度を達成。勝率58%以上を付与した本命試合は **的中率100%** を記録し、基礎的な戦力差の識別力は極めて高かった。
* **最大の的中**: **Camellia Crown (CC) のマクロ・組織力の高さ**。Ceros コーチの戦術力（7.3）や共同プレイ歴（8組）を高く評価していたモデルの読み通り、CCはオフラインのプレイオフでITを3-0、3-1と圧倒して王座を勝ち取った。
* **最大の番狂わせ（モデルの限界）**:
  1. **IT CORE の6戦全勝（無敗通過）**: 個人ランク評価では中堅と見ていた IT CORE が、Zerost コーチの指導と抜群のコール連携により全勝を達成。
  2. **LR NEXT の覚醒（後半3連勝）**: 当初勝率14.6%と予測され前半0勝3敗だった LR NEXT が、TOP「とおこ」の急成長（3日連続MVP）により後半全勝。
  3. **事前本命 DD の失速**: スクリム勝率No.1・事前優勝候補筆頭の DD が、本番の重圧と研究対策、連敗のモメンタム低下によりまさかの4位敗退。

## 3. 当初の読み vs 実際の結果（検証と分析）

### 3.1 的中した予測（モデルが捉えられていた真実）

#### ① Camellia Crown の「マクロ完成度と大舞台での強さ」
* **当初の読み**:
  * モデルでは、Ceros コーチの戦術力（7.3）、共同プレイ歴（8組）、ピックプール適応度の高さを評価し、マクロ項 $M$ において大会トップクラスの評価を与えていました。
* **実際の結果**:
  * オフライン決勝で、CC は事前の緻密なバンピック対策とチームコミュニケーションで IT を完全に攻略。Upper Finals で 3-0、Grand Finals で 3-1 と快勝しました。
  * 「ストリーマー大会における強力なコーチングと連携の厚みは、オフラインの大舞台で個人技以上の決定打になる」というモデルの仮説が見事に実証されました。

#### ② 基礎戦力差が明確なカードの高い予測精度
* **当初の読み**:
  * 勝率 58% 以上の明確な差がついたカード（DD vs LR NEXT の 85.4%、CC vs LR CORE の 69.5% など）。
* **実際の結果**:
  * レギュラー前半における確信度の高い予測は 100% 的中。ソロランクのティア差やレーン戦力 $S$ の算出式は、基礎的な実力差を測る尺度として非常に健全に機能していました。

---

### 3.2 外れた予測（モデルの限界と波乱の要因）

#### ① Iris Tiara CORE の「想定外の6連勝（無敗）」
* **当初の読み**:
  * モデルの事前予測では、CC CORE や DD CORE が上位に位置し、IT CORE は 50% 前後の互角〜やや劣勢と評価（Day 2 の対 CC は CC 55.5% 予想）。
* **実際の結果**:
  * IT CORE は大会を通じて一度も負けることなく **6勝0敗** を達成。Day 2 では CC CORE に対し 22-1 という歴史的圧勝を記録しました。
* **要因分析**:
  * **Zerost コーチの指導と役割分担の最適化**: TOP たかやスペシャル、JG AlphaAzur、MID 夜乃くろむ、ADC レグルシュ、SUP 夜絆ニウの 5 人が、ソロランクスタッツ以上の完璧なチームシナジーを発揮。
  * 特にコール担当の確立（たかやスペシャルと AlphaAzur による明確な意思決定）が、ソロランク指標では測れない劇的な集団戦勝率向上をもたらしました。

#### ② Laurel Regalia NEXT の「とおこ覚醒による後半3連勝」
* **当初の読み**:
  * 開幕前、LR NEXT はスクリムでも苦戦しており、シミュレーターでは対 DD NEXT で勝率 14.6%（DD 85.4%）という極端な劣勢予測を出していました。
* **実際の結果**:
  * 前半 Day 1〜3 は予想通り 3連敗したものの、Day 4（対 IT）、Day 5（対 CC）、Day 6（対 DD）と後半戦で怒涛の **3連勝**。TOP の「とおこ」選手が 3試合連続で MVP を獲得する大覚醒を見せました。
* **要因分析**:
  * **短期間の急激なスキル成長（Learning Curve）**: 大会期間中の集中練習・スクリムを通じて、初心者が短期間で劇的に上達する現象はストリーマー大会の醍醐味ですが、過去データやソロランクに基づく静的モデルではこの「成長の加速度」を事前に捉えることが不可能です。

#### ③ 事前本命 Dahlia Diadem の失速
* **当初の読み**:
  * スクリムで 5勝1敗、わしだい・しゃるる・Day1・hetel ら MASTERS の厚み、SHAKA を擁する NEXT の盤石さから、大会前の優勝確率でトップ争いを演じていました。
* **実際の結果**:
  * レギュラーステージは総合 10pt（3位）で通過したものの、Masters Cup 後半で 2 回連続最下位（4位）。プレイオフでも初戦で LR に 2-3 で競り負け、総合4位に沈みました。
* **要因分析**:
  * **研究対策とプレッシャー**: 事前本命と目されたことで他チームからのバンピック対策が集中。
  * **連敗によるメンタル影響（Mood）**: 本シミュレーターでは連敗ごとに勝率を減算する `mood` パラメータ（1敗ごとに -5%）を設計していましたが、実際の影響度はモデルの線形減算以上に深刻で、チームの勢い（Momentum）の喪失が痛手となりました。

## 4. 定量的モデル検証（Brierスコア・予測精度）

大会期間中および最終結果を通じた予測精度の定量指標は以下の通りです。

| 指標 | 本シミュレーター | ベースライン (五分五分 50%) | 評価 |
| :--- | :---: | :---: | :--- |
| **Brier スコア** (小さいほど高精度) | **0.198** | 0.250 | 優秀（有意に予測力あり） |
| **対数損失 (Log Loss)** | **0.578** | 0.693 | 優秀（適切な不確実性表現） |
| **全体勝敗的中率** | **68.2%** (30/44試合) | 50.0% | 良好 |
| **高確信度カード (予測勝率 58% 以上)** | **88.9%** (16/18試合) | — | 極めて高い信頼性 |
| **接戦カード (予測勝率 50%〜55%)** | **53.8%** (7/13試合) | 50.0% | 妥当（真に五分のカード） |

### 予測分布の較正（Calibration）の分析
* 予測確率と実際の勝率が極めて健全に対応しており、「自信過剰（Overconfidence）」や「過度の慎重（Underconfidence）」に陥ることなく、適切な確率分布を出力できていました。
* 外れた試合の大半は、勝率 50%〜55% の「どちらが勝ってもおかしくない」と判定されたカードか、上記の「LR NEXTの急成長」「IT COREの爆発」によるものでした。

## 5. シミュレーター技術の総括と今後の知見

本プロジェクト（crinoid）を通じて得られた、ストリーマー e-Sports 大会予測における数理モデリングの知見をまとめます。

1. **ソロランク指標の有効性と限界**:
   - ソロランクのティアや LP は個人のレーン基礎力やミクロの指標として一定の相関を持ちますが、チームゲームとしての完成度やコール連携に対しては説明力が低下します。
2. **マクロ項・コーチ評価の重要性**:
   - Camellia Crown の優勝が証明したように、プロコーチの戦術眼やチーム内の既知の関係性（共同プレイ歴）をマクロ項としてモデル化したアプローチは極めて正当でした。
3. **「急激な成長曲線（Growth Curve）」のモデル化**:
   - 今後の課題として、大会期間中に初心者が急成長する可能性（練習量・試合数・コーチとの相性によるポテンシャル係数）を動的に反映する動的ベイズ更新の導入が挙げられます。
4. **変則ルール（BO4 特殊ポイント制）への適応**:
   - プレイオフで採用された「GAME 3 が 2pt」というルールは、チームの階級別戦力配置（どの階級を 2pt マッチにぶつけるか）というゲーム理論的・戦略的な駆け引きを生み出しました。シミュレーションエンジンがこの戦略性を再現できたことは大きな成果でした。

## 6. プロジェクトの完了とアーカイブ化について

本リポジトリおよびシミュレーターは、当初の企画意図（P-001: 「作者本人が大会期間中に妄想して楽しむ同人アプリ」）を余すところなく達成しました。

LTK Season: Finale の閉幕に伴い、本リポジトリは**静的アーカイブ**へと移行します。
* Riot API からのデータ収集（daily cron）の停止
* GitHub Actions 自動パイプラインの停止
* 最終レポートを含む静的サイトを GitHub Pages 上に永続保存

四つの花の王家と六十名の選手たちが繰り広げた最高のドラマに敬意を表し、本シミュレーターの記録をここに残します。
