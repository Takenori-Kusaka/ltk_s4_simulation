# スクリムと本番予測の食い違いのレビュー(2026-10-13)

問い: スクリムで圧勝している階級チームでも本番は負ける、という現状の予測は妥当か。

> 3人のレビューは、AI がプロ選手・プロコーチ・プロ解説の視点を想定して書いた意見です。実在の人の評価ではなく、指摘の材料(検出の層)として扱ってください。

## 結論

**一部妥当(3人とも同じ判定)**。未対戦の相手に不利と出ること自体はありえますが、いまの予測はスクリムの結果をチームの強さにまったく使っていません。これが違和感の主な原因です。

## 何が起きているか(サイトと仕様で確認した事実)

- サイトの根拠欄の「まだ入っていないもの」に「スクリムと本番の結果」があります。チームの強さの当て直し(F-005 Task-2、スクリムの重み 0.25 の Bradley-Terry)と、スクリム数で外部の見立てを弱める λ(F-005 基準3c)は、どちらも仕様だけあって未実装です。
- スクリムは個人の軸の統計にだけ入っています(ソロランク1試合の2倍の重み)。
- LTKDB に載る階級チーム同士のスクリムは 13 試合だけです。DD CORE 5勝1敗(LR に 3-0、IT に 2-1)、DD NEXT 4-0 IT NEXT、CC MASTERS 1-2 LR MASTERS。
- 典型例は DD CORE です。スクリムは 5勝1敗ですが、未対戦の CC CORE には2戦とも 44% と予測されています。対 IT・LR も 58% 止まりです。
- CC CORE が有利になっている主な理由は次の3つです。
  - TOP の差(YUKIO 7.1 vs 酒寄颯馬 6.1)
  - コーチの差(Ceros 7.3 vs わしだい 6.6)
  - 共同プレイ歴(CC 8組、DD 0組)による連携の厚み
- 外部の見立てだけなら DD 有利(CC 41%)です。

## 3人が共通して挙げた見直し点

1. **連携の厚みを共同プレイ歴だけで測っている**。DD はスクリムで連携が機能していることを示しているのに、0 組のまま低く見られている。スクリムの結果で上書きや更新ができるようにする(選手・コーチ)。
2. **スクリムの試合時間と内容**。DD の勝ちには 40 分を超える試合が2つあり、IT には 24 分で敗れている。「圧勝」とは言い切れない(全員)。
3. **二重計上に注意**。スクリムは個人の軸(重み2)にすでに入っている。チームの当て直しと二重に数えないよう整理する(コーチ)。

## 個別の指摘

- **コーチ**: コーチの 15% はレーン側ではなくマクロ側に置き、比重を 10% 前後に下げることも検討する。
- **選手**: ソロランクの差がチームの結果へ効く度合いを抑える。
- **解説**: 「スクリム反映前/後」の勝率と、内訳(個人の軸・外部の見立て)を並べて表示する。44〜56% の試合は「ほぼ互角」と表示し、どちらが有利かを強調しない。

## 実装したときの動きの目安(解説の概算)

- 仕様どおり(事前分布の標準偏差 0.58、重み 0.25)なら、DD CORE の補正は約 +0.11。対 CC は 44% → 47% 前後。
- 重みを 1.0 にしても 52% 前後で、拮抗の範囲を出ません。
- 6 試合では証拠が弱く、5勝1敗の勝率の 95% 区間はおよそ 36〜99% です。スクリムを入れても、CC 戦が大きく DD 有利に振れることはありません。
