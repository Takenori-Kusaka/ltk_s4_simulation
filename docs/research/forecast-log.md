# 試合日ごとの予測と結果の記録

本番の各試合について、試合日より前に公開サイトが出していた勝率と、実際の結果を並べます。外れた試合は理由の見立てを添えます。試合日が終わるたびに行を足します。

- **予測の取り出し方**: 公開サイト(`gh-pages` ブランチ)の配備のうち、試合日の 0 時(JST)より前で最後のものを選び、その JS の束に入っている勝率表(`matches[]` と `stageWinTables`)から読みます。F-004 の予測の凍結(基準11)と同じ切り方です
- **外れた理由の見立て**は AI の推定です。確かめた事実ではありません。補正するかは価値責任者が決めます
- 試合数がまだ少ないため、指標の値は目安です

**読み方(推定)**: 予測が自信過剰だという兆しはありません。見込み 8.35 に対して 10 試合が当たっており、むしろやや控えめです。外れた 4 試合のうち 3 試合は本命の勝率が 53% 以下の五分に近い試合でした。14 試合では、勝率の幅を広げる・狭める補正の根拠にはなりません。

## 補正の候補(価値責任者の判断待ち)

- **勝率の幅の補正はしない**: 上の指標のとおり、14 試合では自信過剰も控えめすぎも言い切れません。試合日ごとにこの表を足し、30 試合ほどで改めて見ます
- **本番の結果の効き方を確かめる**: IT CORE は本番 2 戦 2 勝(どちらも大差)ですが、3 日目の DD 対 IT の CORE は IT 52.6% にとどまります(2026-10-21 の公開サイト)。本番 1 試合の重み(`src/winrate/config.json` の `weights.official` = 2.0)が、個人の評価から作る事前の強さに比べて小さすぎないかを、次の試合日の結果と合わせて見ます
