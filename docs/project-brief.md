## 投資対効果(観点4 / G-1 基準1 / 収益製品向け)

この案件は収益で説明しません。期待効果の類型は「作者本人の娯楽」であり、金額で算定しない理由は販売・収益化の計画が無いためです。

| 項目 | 概算 |
| --- | --- |
| 初期開発費 | (草案)作者の余暇の時間のみ。金額で算定しない |
| コンテキスト基盤の初期整備費 | (草案)事前調査(大会形式・60選手・メタ・過去3シーズンのピック)の取り込み。AI の調査エージェント4本と、作者の確認 2〜4 時間(見積り) |
| 運用費(年) | (草案)大会期間(約6週間)の情報更新。試合日ごとに 15〜30 分の入力(見積り)。サーバー費用なし(ローカル実行) |
| 期待効果(短期) | (草案)開幕(10/15)までに、事前予測とパラメーター変更による再計算ができる |
| 期待効果(長期) | (草案)大会終了(11/22)まで、試合日ごとの結果を入れて予測が更新され続ける。幅: 「Regular Stage の途中まで使う」〜「Playoffs まで毎日使う」 |
| 算定根拠 | (草案)公式日程(Regular 6日・MASTERS CUP 3日・Playoffs 2日)と、1日あたりの入力項目数の見積り |
| 参照した過去案件 | 参照できる過去案件なし |
| **効果が出ない条件** | (草案)開幕までに予測と更新の最小機能が動かない。結果の入力が面倒で作者が更新をやめる |
| AI の利用で期待する成果 | (草案)開幕までのリードタイム(着手から最初の予測が出るまでの日数)を短くする。差し戻し(受入基準を満たさず作り直した回数)を指標にする |
| AI を使わない場合との比較の基準値 | 基準値なし |
| AI の利用の拡大と停止の基準 | (草案)差し戻しが1機能あたり3回を超えたら、AI に任せる範囲を狭めて作者が設計を書く。開幕に間に合う見込みが立てば、追加機能の実装も AI に任せる |
