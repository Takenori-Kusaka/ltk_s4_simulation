# P-001 LTK Season: Finale シミュレーター

## 案件の目的

LoL ストリーマー大会「League The k4sen(LTK)Season: Finale」(2026-10-15〜11-22)について、勝率・各試合日の勝者・選手の活躍・ピックを予測するローカルのシミュレーターを作る。新しい情報や実際の大会結果を取り込んで予測を随時更新する。個人の同人アプリであり、目的は作者本人が楽しむこと。販売計画・事業計画は持たない。

企画書(`docs/project-brief.md`)は D-0 承認の後に作る。作ったらここへリンクと要約を書く。

## いま作っているもの

- 機能仕様は未作成(プロセス構成の初期化の段階)
- 事前調査: 大会形式・ロスター・各選手の情報の収集(`docs/research/` へ置く予定)

## 暗黙の前提

- 1名体制(作者本人が全席を兼務)。G-6 独立レビューは未達
- 公開情報(公式 X、ニュース記事、Wiki、ランクボード)だけを入力にする
- 予測は娯楽目的であり、誤っても作者が困るだけ(CL0)

## 決まっていないこと

- 技術スタック(`undetermined`。SG-0 までに ADR で確定する)

- UI の形態(CLI / ローカル Web / ノートブック)
- 大会で使われるパッチの確定値
- `tmp/` の事前分析メモと、公式発表のロスター(LR NEXT SUP=No.1005、各階級コーチ)の差分の扱い
