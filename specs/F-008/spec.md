# F-008 レーダーを重ねた比較

## 背景

作者は「CC CORE vs DD CORE」のように、チームの階級どうし、選手と対面の選手を、レーダーチャートを重ねて簡単に比べたい(価値責任者の要望、2026-10-08)。F-002 は1つの対象のレーダーを出し、比較の画面をスコープ外にしている。この機能が比較を担う。

## 受入基準

| # | 型 | 受入基準 |
| --- | --- | --- |
| 1 | イベント駆動 | 比較の画面で2つの対象(選手 / チームの階級 / チーム全体のうち同じ種類の2つ)を選んだとき、システムは2つの5軸レーダーを色を変えて1つの図に重ねて表示しなければならない |
| 2 | イベント駆動 | 2つの対象を重ねて表示したとき、システムは軸ごとに両者の点数と差(小数第一位)を表に表示しなければならない |
| 3 | イベント駆動 | 選手のページで「対面と比較」を選んだとき、システムは Regular Stage の日程から次に当たる相手チームの同じ階級・同じロールの選手を2つ目の対象にして、比較の画面を開かなければならない |
| 4 | イベント駆動 | 試合の分析ページ(F-005)で「比較」を選んだとき、システムはその試合の両チームの同じ階級を2つの対象にして、比較の画面を開かなければならない |
| 5 | ユビキタス | システムは比較の画面の状態(2つの対象)を URL に持ち、その URL を開くと同じ比較を表示しなければならない |
| 6 | 望ましくない事象 | 種類の異なる2つ(選手とチーム)を選んだ場合、システムは比較を表示せずに、同じ種類を選ぶよう求める文を表示しなければならない |

各基準には、違反すると失敗するテストが1つ以上必要です。

## スコープ外

- 3つ以上の対象の比較
- 階級をまたいだ比較(NEXT と CORE)。相対評価のため意味を持たない(F-002 基準6)
- 比較の結果からの勝率の計算(F-005)

## 前提

| # | 前提 | 崩れたときの影響 |
| --- | --- | --- |
| 1 | F-002 の5軸の点数と相対評価が使える | 比較の値を出せない |

## 非機能の要求

| 項目 | 要求 |
| --- | --- |
| 応答時間 | 比較の画面の表示が作者のスマホで 1 秒以内 |
| 同時実行 | 考慮しない |
| 監査ログ | 不要 |
