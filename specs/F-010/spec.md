# F-010 階級チームの強さと戦い方、全階級チームの総合評価

## 背景

価値責任者は、階級ごと(例: CC CORE)の評価は5人全体のチームとしての評価と特性であるべきだと述べた(2026-10-08)。オブジェクトをどれくらい優先するか、BOT ゲームか TOP ゲームか、先に集まるのかレーン戦を優先するのか、である。全階級(例: CC)の評価は、個人とチームの掛け合わせによる総合で、大会のルールに合わせて強い階級とコーチングをどう生かして一つのチームにできるかを示すべきだとも述べた。

この機能は ADR-0005 の3層の評価のうち、階級チームと全階級チームの層を作る。個人の層は F-009。

価値責任者は、階級チームの総合力にはメインコーチの実力も大きく関係すると述べた(2026-10-09)。例えば IT CORE のコーチ Eugeo は、過去の LTK の実績でも言語化力でもコーチとして高い水準にあり、IT CORE の底上げになっている。選手としての評価とコーチとしての評価は別物なので、階級チームに5つのレーンのロールとは別に「コーチ」の枠を設け、選手とは別の評価軸で評価し、総合力へ反映する。

価値責任者は、仕様の見直しで次の2点を決めた(2026-10-09)。

- **D1**: コーチの評価を、勝率の計算に使う階級チームの戦力にも足す(重み 0.15。選手5人の合計を 0.85 に縮める)。docs/design/team-model-algorithm.md 節2.1 の「S = Σ ロールの重み × 選手の総合」だけの式を、この決定で置き換える。勝率が尖りすぎないことは、常識の検査 K-08(Finale の結果が入る前に、NEXT・CORE で勝率 0.80 を超える組が無い)で引き続き確かめる。コーチの評価軸の重みは評価設定の初期値(AI の起案)のまま
- **D2**: 過去の LTK(S3)の集計値は、出典つきで公開のページに出してよい。試合ごとの行(生データ)は出さない

価値責任者の決定(2026-10-12): 継続性が過去の LTK の出場記録だけで数えられ、今季に結成されたチームのスクリムでの連携の実績が評価のどこにも入っていなかった(例: DD CORE は名簿の階級チーム同士のスクリムを 5 人そろって 6 試合戦ったが、継続性の組は 0)。今季のスクリムで 5 人がいっしょに戦った組も継続性に数える(基準 4b)。スクリムは課題を洗い出す場でもあるため、勝敗とキル差は使わず、いっしょに戦った試合の数だけを使う。

既存の画面との関係: チームのページは F-009 の8軸の相対評価のレーダー(階級ごとと3階級の平均)とチームの指標(視界・オブジェクト・マクロ。src/rating/team-indicators.ts)を src/app/rating/view.ts で表示している。F-010 はこれらを置き換えず、強さの軸・戦い方の特性・コーチの枠・総合の軸を加える(基準19b)。

## 用語

- **階級チーム**: あるチームのある階級の5人(例: CC CORE)。NEXT と CORE はコーチの枠を持つ。MASTERS はコーチの枠を持たない
- **全階級チーム**: あるチームの3階級15人とコーチ(例: CC)
- **コーチの枠**: NEXT と CORE の階級チームの6人目の枠。担当コーチ(公式発表。MASTERS の選手が兼ねる)を置く
- **選手の総合**: O = 5.0 + Σ (1/8) × (x_k − 5.0)。x_k は F-009 の8軸の表示の点数(調子の係数を掛けた後)。2026-10-08 確定(docs/design/team-model.md 冒頭)
- **コーチの総合**: C = コーチの評価軸5つの平均(基準5b)
- **戦力 S**(階級チームの強さ。勝率と総合の軸に使う値。相対評価の前の値): NEXT・CORE は S = 0.85 × Σ w_r × O_r + 0.15 × C、MASTERS は S = Σ w_r × O_r。w_r はロールの重み(MID 0.24 / JG 0.21 / SUP 0.21 / TOP 0.17 / ADC 0.17)。0.85・0.15 は D1 による評価設定の初期値
- **相対評価**: F-002 基準6 の換算。同じ階級の4チームの値を平均と標準偏差で標準化し、5.0 + 2.0 × 標準化した値を 0.0〜10.0 に切り詰める。4チームの値がすべて同じ場合は全チーム 5.0
- **コーチの評価軸**(選手の8軸とは別): 指導の実績 / 言語化力 / 戦術とドラフトの設計 / 選手時代の知見 / チームとの相性
- **強さの軸**: 戦力 / 連携の厚み / 司令塔 / 継続性 / 指導 / ピックの幅 / フィアレス耐性
- **戦い方の特性**: 序盤型⇄終盤型 / レーン戦重視⇄集合重視 / 重心(TOP・JG・MID・BOT)/ オブジェクトの優先度。良し悪しではなく向きを示す。視界は F-009 のチームの指標「視界」に任せ、特性に入れない
- **総合の軸**: Regular Stage の得点力 / MASTERS CUP の力 / エースの階級 / 階級の均衡 / コーチングの活用 / 一体感 / チーム設計(ウィークサイドの作り方)
- **ウィークサイド**: 資源(ゴールド・JG の支援)を他のレーンへ回すために、少ない資源で耐えることを任せるレーン
- **資源が少ない試合**: ある選手の評価の試合(F-009)のうち、チームの獲得ゴールドに占める本人のゴールドの割合が、本人の評価の試合の中で下位 3 分の 1 に入る試合
- **得意チャンピオン**: 選手の評価の試合(F-009)で、大会のロールの試合数が多い順の上位5体
- **勝てるチャンピオン**: 選手の評価の試合(F-009)の大会のロールで、3 試合以上使い、勝率が 50% 以上のチャンピオン
- **過去の LTK の出場記録**: S1〜S3 の公式発表の、シーズン・チーム・階級・選手の対応
- **LTK3 の集計**: LTK3 の公開スプレッドシート(第三者)の本番・スクリムの試合ごとの記録から作った、(チーム・階級)と(チーム・階級・ロール)ごとの集計値だけのスナップショット(基準21b)。S1・S2 には試合ごとの記録が無いので、戦い方の特性には S3 だけを使う
- **継続した選手**: 階級チームの5人のうち、LTK3 の集計に含まれる選手。**継続の割合**はその人数 ÷ 5

### 階級チームの戦い方の特性

戦い方の特性の値は −1.0〜+1.0 とする。標準化は LTK3 の集計の全階級チームを母集団とし、z = (値 − 母集団の中央値) ÷ 母集団の標準偏差、特性の値 = z ÷ 2 を −1.0〜+1.0 に切り詰めた値とする。階級チームの値は、継続した選手が S3 に所属した(チーム・階級)ごとの値を、その(チーム・階級)に所属した継続した選手の人数で重み付けした平均とする。

### 価値責任者の見立て(2026-10-12)

価値責任者の方向(2026-10-12): スクリムと顔合わせを見て伝えたチームとコーチの見立ては、メモではなく評価の入力である。あらゆる情報は勝率の予測の精度を上げ、個人とチームの能力を正しく評価するためのもので、重みは初期値から結果に合わせて調整していく。原文と対応づけは `docs/research/grounds/owner-review-scrims-20261012.md`。記録は選手の見立て(F-009 基準37)と同じ `docs/research/grounds/normalized/owner-views.json` に、対象を階級チーム(例: `DD-CORE`)またはコーチとして置く。

## スコープ外

- 試合ごとの勝率の推定(F-005)。この機能の戦力 S は F-005 の入力になる
- ピックとチームの作戦の予想(F-006)

- リスナー参加のスクリムと、名簿の階級チーム以外とのスクリム(F-004 決定 D2)

- 価値責任者の見立てを戦い方の特性(向きで、良し悪しではない)と継続性に加えること。見立ては強さの軸(連携の厚み・司令塔)とコーチの評価軸にだけ加える(基準23・24)
